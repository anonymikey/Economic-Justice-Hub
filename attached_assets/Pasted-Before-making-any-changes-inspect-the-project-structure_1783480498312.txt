Before making any changes, inspect the project structure.

1. Check whether these pages already exist:
- Research & Knowledge
- Insights
- Contact

2. If a page already exists:
- Preserve its route.
- Preserve navigation links.
- Replace its content with the new content below.
- Redesign the page without breaking existing functionality.

3. If a page does not exist:
- Create a new page.
- Create the appropriate route.
- Add it to the navigation menu.

Maintain consistency with the new Economic Justice Forum branding while giving every page its own unique layout, animations and visual identity.

Global Design Requirements

- Deep Navy (#08152F)
- Gold (#C9A24A)
- White
- Light Gray backgrounds
- Elegant serif headings
- Modern sans-serif body text
- Responsive on all devices
- Accessible
- Smooth scrolling
- Fade-up animations
- Cards lift on hover
- Premium institutional appearance

Avoid reusing the exact same layout on every page.
