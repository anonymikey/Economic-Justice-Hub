STEP 1 — INSPECT THE PROJECT
==================================================

Before making ANY changes:

Inspect the existing codebase and determine:

• Current Supabase client configuration
• Existing authentication flow
• Existing database queries
• Existing environment variables
• Existing migrations
• Existing storage usage
• Existing admin functionality
• Existing protected routes

Produce a summary showing:

- Files using Supabase
- Required environment variables
- Expected database tables
- Storage buckets referenced
- Existing RLS expectations

Do NOT make assumptions.

STEP 2 — VERIFY NEW SUPABASE READINESS
==================================================

If additional environment variables are required,
list them clearly.
