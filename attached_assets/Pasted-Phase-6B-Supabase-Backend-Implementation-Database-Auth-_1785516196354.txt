The Phase 6A audit is approved.

Begin implementing the Supabase backend using the new Supabase project.

Scope

Implement the backend only.

Do not redesign the website.

Do not change branding, colors, animations, layout, typography, SEO, metadata, routing, or HQ content.

Do not modify the completed Home, Philosophy, Research, Footer, Cookie Banner, or visual work unless required for backend integration.

1. Connect the project to Supabase

Use the existing frontend client.

Connect the API server to the new Supabase project.

Ensure the project uses:

VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY

users
events

contact_submissions
newsletter_subscriptions
donations
pre_approved_admins

Use UUID primary keys.

Use consistent timestamp naming.

Use created_at and updated_at where appropriate.

Create indexes for:

published
created_at
date_iso
email
submitted_at

Add the required UNIQUE constraints.

full_name

is_admin = false

5. Row Level Security

Enable RLS.

Create secure production policies.

Requirements:

contact submissions

Do NOT use broad authenticated = true policies.
